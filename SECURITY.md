## Reporting a Vulnerability

Security is paramount for local-first developer tools and database clients. If you discover a security vulnerability within GhostBase:

1. **Do not disclose publicly** in an open issue.
2. Please report security issues privately via GitHub Security Advisories or reach out directly to **[contact.4yk5@proton.me](mailto:contact.4yk5@proton.me)**.
3. Include detailed steps to reproduce the vulnerability.

We take all security reports seriously and will investigate, patch, and release a fix promptly.
